# Настройка YouTube Music для BSC

BSC работает с YouTube Music через **YouTube Data API v3**. Приложение запускается локально и не имеет
собственного сервера, поэтому OAuth идёт через loopback-адрес, а перехват кода выполняет само
приложение.

---

## 1. Создать проект

1. Открой https://console.cloud.google.com и войди под своим Google-аккаунтом.
2. Создай проект — или выбери существующий.
3. **APIs & Services → Library**, найди **YouTube Data API v3** и нажми **Enable**.

Без включённого API запросы будут отклоняться с `accessNotConfigured`, а не с чем-то, что выглядело бы
как ошибка в приложении.

---

## 2. Создать OAuth-клиент

1. **APIs & Services → Credentials**.
2. **Create credentials → OAuth client ID**.
3. В поле **Application type** выбери **Desktop app**.

Назови клиент, например `BSC`, и сохрани.

> **Почему именно Desktop app, а не Web application.** Это единственное место, где тип клиента меняет
> поведение приложения.
>
> У Desktop-клиента в консоли Google **нельзя зарегистрировать redirect URI** — он работает по
> loopback-адресу и принимает любой порт. Но обмен кода на токен **обязан повторить**
> `redirect_uri` из authorize-запроса (`http://localhost:8889/callback`): без него Google отвечает
> `invalid_request: Missing parameter: redirect_uri`, при несовпадении — `redirect_uri_mismatch`.
> Приложение сделано под Desktop-тип, и это осознанный выбор.
>
> Если создать Web application client, вход упадёт на `redirect_uri_mismatch`.

Из карточки клиента понадобится **Client ID**. **Client Secret** приложение показывает один раз — если
потерял, удали клиент и создай новый.

---

## 3. Войти

Если сборка шла с общими ключами (раздел 3.1), всё сводится к одной кнопке.

1. Открой BSC → **Настройки** → раздел **«Подключённые аккаунты»** → **YouTube Music**.
2. Нажми **«Войти через YouTube»**.
3. Если общих ключей в сборке нет (или нужны свои) — нажми текст **«У меня свои ключи»**, вставь
   **Client ID** и **Client Secret** (раздел 2), нажми **«Сохранить»**, затем **«Войти»**.

Приложение откроет окно авторизации на `accounts.google.com`. Redirect перехватывается на
`http://localhost:8889/callback` — слушать этот порт не нужно, приложение читает код до загрузки
страницы и закрывает окно.

### 3.1. Общие ключи для входа в один клик (сборщику)

Чтобы юзеры не регистрировали проект сами, вшей Desktop-app клиент в сборку — значения читаются
**только** из окружения на момент компиляции и в git не попадают:

```bash
export BSC_YOUTUBE_CLIENT_ID='...'
export BSC_YOUTUBE_CLIENT_SECRET='...'
npm run package:mac   # или package / package:win / dev
```

В CI это Secrets репозитория, экспортированные шагом сборки. Без них приложение собирается как
раньше и просит свои ключи — ничего не падает.

Про безопасность и цену — честно:

- Google документирует installed apps как неспособные хранить секреты, так что встраивание —
  штатный паттерн, а не утечка. Но секрет из бинарника извлекается, поэтому: значения живут
  только в env сборки (никогда в коде, логах и localStorage — вшитые ключи туда не сохраняются
  даже после успешного входа), rotation — новым релизом через встроенный апдейтер.
- Квота проекта делится на всех (10 000 единиц/сутки; поиск — 100 за вызов). Свои ключи
  остаются запасным путём для активных.
- Consent screen с чувствительными скоупами требует верификации, иначе — предупреждение
  о непроверенном приложении и лимит. Это отдельная процедура в Cloud Console.

## Области разрешений

Приложение запрашивает минимальный набор:

| Область | Зачем |
|---|---|
| `youtube.readonly` | понравившиеся видео, плейлисты |
| `openid`, `email`, `profile` | имя аккаунта |

**`force-ssl` не запрашивается.** Он нужен для записи оценки («лайк»), и приложение его не просит:
просить доступ на запись ради одной недоступной функции — плохой обмен. Воспроизведение при этом
работает: прямая ссылка на аудио достаётся локально через sidecar yt-dlp (см. `docs/youtube_music_tauri.md`),
а не через API.

---

## Страница автора

Канал открывается как страница автора: имя, аватар, баннер, подписчики, число видео, вкладки
«Треки автора» (плейлист загрузок, 3 запроса) и «Плейлисты автора». Лайки канала и подписки
не показываются — Data API чужие подписки не отдаёт, а публичных лайков канала не существует.

---

## Жёсткие ограничения YouTube

Это не баги приложения, а правила самого YouTube. Их стоит знать заранее.

| Ограничение | Что это значит |
|---|---|
| **Поиск — 100 вызовов в сутки** | `search.list` стоит 100 единиц квоты в день. Это самая жёсткая рамка: после неё поиск перестаёт работать до следующих суток |
| **Понравившиеся — максимум 1000** | `videos.list?myRating=like` отдаёт не более 1000 видео, сколько ни листай. Приложение сообщает об этом отдельным флагом, чтобы обрезанный список не выглядел полным |
| **Квота проекта — 10 000 единиц/сутки** | Остальные запросы стоят по 1–100 единиц |
| **Воспроизведение через sidecar** | YouTube не отдаёт аудиопоток через API, поэтому аудио-ссылку достаёт локальный yt-dlp (~35 МБ в составе приложения). Ссылки живут несколько часов и обновляются при каждом нажатии play |

---

## Фильтрация «только музыка»

YouTube отдаёт **все** понравившиеся видео — лекции, стримы, всё подряд. `videos.list` не умеет
фильтровать по категории, поэтому отсев делается на стороне приложения: берутся видео с категорией
`10` (Music).

Это эвристика, а не гарантия: видео с музыкой бывает и в других категориях. Приложение показывает лишнее,
а не прячет нужное — ошибка «показать лишнее» исправляется глазами, ошибка «спрятать полезное» незаметна.

## Если вход не работает

| Симптом | Причина |
|---|---|
| `invalid_request: Missing parameter: redirect_uri` | Старая версия бэкенда не слала `redirect_uri` в token-запросе — обновись |
| `redirect_uri_mismatch` | Создан **Web application** клиент вместо **Desktop app** — см. раздел 2, либо `redirect_uri` в token-запросе отличается от authorize-запроса |
| `accessNotConfigured` | Не включён **YouTube Data API v3** в проекте |
| `invalid_client` | Неверный Client ID или Client Secret |
| `quotaExceeded` | Исчерпана дневная квота. Поиск — 100 вызовов в сутки, это частая причина |
| Токен истёк (`нужен refresh`) | Access token живёт час; приложение обновляет его само по сохранённым Client ID/Secret. Если не помогло — выйди и войди заново, чтобы данные пересохранились |
| Список понравившихся обрывается на 1000 | Ограничение API, а не приложение. Список помечен как обрезанный |
| Лайки ничего не делают | Записи оценки не реализованы: под них не запрашивается `force-ssl` |
